# Process Design Document

## Process Name

Employee Onboarding Automation

## Business Objective

Automate the registration of employee records from an input file into a web application and produce a detailed execution report.

## Trigger

The process starts when a valid input file is available in the input folder.

## High-Level Process

1. Check for an input file.
2. Read and validate employee records.
3. Log in to the web application.
4. Process each employee record.
5. Capture the result of each transaction.
6. Save screenshots and logs when required.
7. Generate an output report.
8. Archive the processed input file.
